### 常用公式

#### 常用函数的泰勒展开式

| **函数** f(x)       | **泰勒展开式（在** x = 0 **处）**                                                                                                              | **收敛区间**                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| $e^x$             | $\displaystyle \sum_{n=0}^\infty \frac{x^n}{n!}$                                                                                      | $(-\infty,\ \infty)$     |
| $\sin x$          | $\displaystyle \sum_{n=0}^\infty \frac{(-1)^n x^{2n+1}}{(2n+1)!}$                                                                     | $(-\infty,\ \infty)$     |
| $\cos x$          | $\displaystyle \sum_{n=0}^\infty \frac{(-1)^n x^{2n}}{(2n)!}$                                                                         | $(-\infty,\ \infty)$     |
| $\ln(1 + x)$      | $\displaystyle \sum_{n=1}^\infty \frac{(-1)^{n+1} x^n}{n}$                                                                            | $(-1,\ 1]（条件收敛于 1）$      |
| $\frac{1}{1 - x}$ | $\displaystyle \sum_{n=0}^\infty x^n$                                                                                                 | $(-1,\ 1)（等比数列）$         |
| $\arctan x$       | $\displaystyle \sum_{n=0}^\infty \frac{(-1)^n x^{2n+1}}{2n+1}$                                                                        | $(-1,\ 1]（条件收敛于 1）$      |
| $\arcsin x$       | $\displaystyle \sum_{n=0}^\infty \frac{(2n)!}{4^n (n!)^2 (2n+1)} x^{2n+1}$                                                            | $[-1,\ 1]$               |
| $(1 + x)^\alpha$  | $\displaystyle \sum_{n=0}^\infty \binom{\alpha}{n} x^n,其中 \binom{\alpha}{n} = \frac{\alpha (\alpha - 1) \cdots (\alpha - n + 1)}{n!}$ | $(-1,\ 1)，若 \alpha 非正整数$ |

#### 多元泰勒公式/结合拉格朗日中值定理

$$
\begin{align}f(x_0+h,y_0+k)=f(x_0,y_0)+(\frac{\partial}{\partial x}h+\frac{\partial}{\partial y}k)f(x_0,y_0)+\frac{1}{2!}(\frac{\partial}{\partial x}h+\frac{\partial}{\partial y}k)^2f(x_0,y_0)+···\\+\frac{1}{n!}(\frac{\partial}{\partial x}h+\frac{\partial}{\partial y}k)^nf(x_0,y_0)+R_n\end{align}
$$

其中余项：$R_n=\frac{1}{(n+1)!}(h\frac{\partial}{\partial x}+k\frac{\partial}{\partial y})^{n+1}f(x_0+\theta h,y_0+\theta k)\quad,\quad0<\theta <1$
n=0时，叫做二元拉格朗日中值定理

###### 互相转化

- gauss公式（散度公式）（曲面积分用三元累次积分）_取外侧啊！_
  散度$div A=\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}.$衡量向量场的流量：源点/流出/0 \*电荷密度，膨胀or压缩，梯度场的逆操作etc.
- stokes公式（二型曲线曲面互相转化）（旋度公式）（三元曲线积分用曲面积分）（也可以再套一个gauss公式（？））
  $\oint_LPdx+Qdy+Rdz=\iint_\Sigma\begin{vmatrix}dydz&dzdx&dxdy\\\frac{\partial}{\partial x}&\frac{\partial}{\partial y}&\frac{\partial}{\partial z}\\P&Q&R\end{vmatrix}=\iint_\Sigma\begin{vmatrix}cos\alpha&cos\beta&cos\gamma\\\frac{\partial}{\partial x}&\frac{\partial}{\partial y}&\frac{\partial}{\partial z}\\P&Q&R\end{vmatrix}$
  注意第二行没有具体大写字母！函数由第三行提供
  其中旋度为$rotA=\begin{vmatrix}i&j&k\\\frac{\partial}{\partial x}&\frac{\partial}{\partial y}&\frac{\partial}{\partial z}\\P&Q&R\end{vmatrix}$
