# 接口

## 功能

【数据缓冲】协调很快的CPU和很慢的外设
【通信】

- 【串行】一位一位传数据：速度相对慢，但线少成本低，适合远距离传输
- 【并行】线多、成本高、容易受到干扰；适合远距离
  【控制】中断、定时器
  【状态】数据格式转换、状态反馈、控制&地址译码
  【汇编访问接口】
- 内存映射：外设寄存器直接被映射到IO地址空间
- 端口映射：外设寄存器在独立的IO地址空间

# 计算机数据格式与数制

- 0x和H都是十六进制前/后缀表示
- 压缩BCD：一个字节存两位十进制数
- 非压缩BCD：一个字节存一位十进制数
- 一个word16位
- 数进入subnormal number的范围之内后计算特别慢：指数部分全0但是尾数部分不全0
- 需要区分+0和-0来做近似计算
- 浮点具有舍入误差，大数吃小数
- 加速AI出现了新的浮点格式
