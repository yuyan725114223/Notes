实际推断原理：概率很小的事件实际上不发生
\*可能三个都两两独立但是不相互独立
X=X(e)为实值单值函数，称为随机变量
分布函数F(x)=P(X<=x)，对任意函数x
并非积分，毕竟是单点分布离散型，积出全为0
称X为连续型随机变量，其中    称为X的概率密度函数，简称密度函数
此时F(x)为积分/面积

### 变量分布

#### 一、0，1分布：X~0-1(p);B(1,p)

#### 二、伯努利分布

设A在n重贝努利试验中发生X次，称X服从参数为n,p的二项分布，记X~B(n,p)
**excel**
f=BINOM.DIST(10,100,0.05,TRUE)

- **number\_s**：成功次数（这里是 10）
- **trials**：试验次数（这里是 100）
- **probability\_s**：单次试验成功的概率（这里是 0.05）
- **cumulative**：逻辑值（TRUE 或 FALSE）
  - TRUE 表示计算**累计分布函数** P(X \leq number\_s)
  - FALSE 表示计算**概率质量函数** P(X = number\_s)

#### 三、泊松分布(Poisson分布）称X服从参数为λ的泊松分布，记$X\sim P(\lambda)$

$P(x=K)=\frac{\lambda^k e^{-\lambda}}{k!},k=1,2,3,…,\lambda>0$

- 泊松定理：二项分布与泊松分布有近似结果，拆开即得证
  _二项分布概率的一种估计_
  $当n>10,p<0.1时，有C^k_np^k(1-p)^{n-k}\approx \frac{\lambda^k e^{-\lambda}}{k!},其中\lambda=np.$
  **excel**
  \=POISSON.DIST(2,5,1)

#### 四、超几何分布

$P(x=k)=\frac{C^k_aC^{n-k}_b}{C^n_N},k=l_1,l_1+1,…l_2，其中l_1=max(0,n-b),l_2=min(n,a)$
\*一袋中有a个白球，b个红球，a+b=N,从中不放回地取n个球，设每次取到各球的概率相等，以X表示取到的白球数，则X服从超几何分布

#### 五、几何分布

$P(x=k)=p(1-p)^{k-1}$
\*从生产线上随机抽产品进行检测，设产品的次品率为p，0\<p<1，若查到一只次品就得停机检修，设停机时已检测到X只产品，则X服从参数p的几何分布

#### 六、巴斯卡分布

$P(X=k)=C_{k-1}^{r-1}p^r(1-p)^{k-r},k=r,r+1,r+2,…$
\*独立重复地进行试验，每次试验的结果为成功或失败，每次试验中成功的概率均为p，0\<p<1,试验进行到出现r 次成功为止，以X表示试验次数，则X服从参数为(r,p)的巴斯卡分布。

### 数字特征

#### var

相互独立变量：直接相加；系数：平方

| 0－1分布      | p               | p(1-p)               |
| ---------- | --------------- | -------------------- |
| 二项分布B(n,p) | np              | np(1-p)              |
| 泊松分布       | λ               | λ                    |
| 均匀分布U(a,b) | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| 指数分布       | $\frac{1}{λ}$   | $\frac{1}{λ^2}$      |
| 正态分布       | μ               | $σ^2$                |
化成标准正态分布的方法：期待的概率值-λ/σ，记得出的结果为标准化变量
