# lec10 量子纠错原理

【背景】

1. 量子信息错误是连续的
2. 量子不可克隆
3. 测量量子会破坏它
   【假设】错误的概率幅度出现的非常小，则 ∣e1⟩≈∣e4⟩≈∣e0⟩

- ∣e0​⟩∣0⟩→∣e1​⟩∣0⟩+∣e2​⟩∣1⟩
- ∣e0⟩∣1⟩→∣e3⟩∣0⟩+∣e4⟩∣1⟩
- _这里因为注意第二个bit，就是一致的项基本相等，因为默认弱耦合_
  【设置】分解错误
  通过一些代数变换，我们可以把上面的过程写成：
  ∣e0⟩∣ψ⟩→(∣d⟩I+∣a⟩X+∣b⟩Y+∣c⟩Z)∣ψ⟩
  _这里矩阵放在右边没啥关系 毕竟也可以和右边的$｜\psi$>作用_
  其中：
- I：无错误
- X：比特翻转（|0⟩ ↔ |1⟩）
- Z：相位翻转（|+⟩ ↔ |−⟩）
- Y：比特+相位翻转
  使用辅助bit：错误综合症：告诉我们which bit出错了&如何修正
  ![[图源/图源1-7.30/Pasted image 20260525120256.png|400]]
  注意这里最右边的意思是如果x和y均为1则把上面3个都反转
  【概念】
- 【+1本征空间】：所有特征值为+1的向量所长成的空间
- 【稳定子】：一个算符，通常是pauli算符的张量积，作用在编码态上是稳定的（即编码态的本征值为1，与编码空间的概念相对应）
- 【编码空间】：
  - 所有稳定子的+1向量构成的公共空间（取交）
  - 如果有（编码空间内的）向量对于某个稳定子的特征值不是1，说明出现了错误，需要量子纠错
- 如何区分张量积和矩阵乘法？看看空间：张量积是把不同空间的算符“拼”成一个更大的算符；矩阵乘法是在同一空间内作用
- 【反对易】：交换之后会变成负的
  【测量方法】：
- 可以通过测量稳定子查看出来到底哪里出了问题
- 非破坏测量：测一下算符的特征值，如果结果是 |0⟩，说明状态是 +1 本征态；如果结果是 |1⟩，说明状态是 -1 本征态
- error operator和stablizer一定对易？丕定，但是会选择stablizer使得尽可能使每一种错误都有对应的对易算符来给它纠错，所以选择了几个pauli算符的乘积作为稳定子算符
  【结果】：
- 每种u1，u2的测量唯一对应一种出错方式（正确也算一种），so可以正确纠正它
- 注意3bit码只能进行bit翻转的纠错，如果需要更广泛的纠错需要使用更复杂的编码，比如9bit码&稳定子码
  【两种方法区别】？没啥区别，第二种更加通用，实现基本相同

## Landau-Zener Toy Model

【一个量子bit】把哈密顿量比做地形

- 【经典势能】可控偏置场$\epsilon$（z方向的外力？）
  - - **σz 项**代表一个沿z方向的磁场。这个磁场的大小就是 ϵ（严格说是 ℏϵ/2，但物理本质由 ϵ 决定）。
  - **“偏置”** 的意思就是**偏向哪一边**。你可以把它想象成**一个倾斜的斜坡**：
    - 如果 ϵ 是一个很大的正数，那么 ∣0⟩ 态（对应z方向向上）的能量就**更低**，就像斜坡向右边倾斜，球会滚到右边（∣0⟩）。
    - 如果 ϵ 是一个很大的负数，那么 ∣1⟩ 态（对应z方向向下）的能量更低，斜坡向左边倾斜，球会滚到左边（∣1⟩）。
  - 所以我们通过调节 ϵ，就可以**控制哪个态是“谷底”**。这正是我们“捏黏土”时改变地形的手段。
- 【量子动能】固定的隧穿振幅$\Delta_{min}$（能量间隙）（让量子比特能在|0⟩和|1⟩之间来回跳，即x方向的固有属性）。
  - - **σx 项**代表一个沿x方向的磁场。它的作用是**让量子比特在 ∣0⟩ 和 ∣1⟩ 之间来回跳跃**——这叫做“量子隧穿”。
  - **Δmin​** 就是这种跳跃的**固有频率**（或强度）。Δmin​ 越大，跳跃得越快，粒子越不容易被“困”在某一边。
  - 在绝热计算中，Δmin 通常是**固定的**，不随时间变化。它代表了一个恒定的“量子抖动”。
- 哈密顿量写为![[图源/图源1-7.30/Pasted image 20260608102319.png|150]]
- 系统能量取决于合力大小$\Delta=\sqrt{\epsilon^2+\Delta_{min}^2}$
- 基态和第一激发态之间的能隙让最优解稳定
- 我们从 ϵ 是一个很大的负数开始。此时，能量最低的是 ∣1⟩ 态（你可以认为这是初始的“圆球”黏土）；然后，我们慢慢地增加 ϵ，让它一直变到一个很大的正数。此时，能量最低的变成了 ∣0⟩ 态（这就是我们想要的“铁塔”形状）。
- 【绝热演化】时钟保持在当前的最低点
- 【非绝热演化】被困在原来的|1>状态/两者的混合，也就是我们不想看到的“激发”。
- 跟丢的概率：$P_{跃迁}=exp(-\frac{\pi}{2}\frac{\Delta_{min}^2}{\epsilon})$
- 能量间隙越小/$\epsilon$变化速度越快：跃迁概率越大，意味着计算失败
