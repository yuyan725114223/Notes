## 复杂度
### 空间
递归～栈的深度
>The Fibonacci number sequence {FN​} is defined as: F0​=0, F1​=1, FN​=FN−1​+FN−2​, N=2, 3, .... The space complexity of the function which calculates FN​ recursively is:
>A.O(logN)
>B.O(N)
>C.O(FN​)
>D.O(N!)
	B.因为算了N个值，时间复杂度为O(2^n)
### 主定理
T(N)=aT(N/b​)+f(N)，考虑其时间复杂度
通过递归树分析和数学归纳法的结合，我们得出了主定理的三种情况：
- **情况 1**： f(N)=O(N^d), d<log⁡ba，时间复杂度为 O(Nlog⁡ba)。
- **情况 2**： f(N)=O(N^d), d=log⁡ba，时间复杂度为 O(N^log⁡ba\*log⁡N)。
- **情况 3**： f(N)=O(N^d), d>log⁡ba，时间复杂度为 O(f(N))。

- 顶点 xx 的**深度(depth)**：从根节点出发到 xx ​ 的路径长度，规定 depth(root)=0。

- 树的**degree​**：节点的儿子数量的最大值

#### 尾递归
> 普通递归：
- def factorial(n): if n == 1: return 1 else: return n * factorial(n - 1)

>尾递归
- def factorial_tail_recursive(n, accumulator=1): if n == 1: return accumulator else: return factorial_tail_recursive(n - 1, accumulator * n)
#### 二叉搜索树
**删除（Delete）**：
**有两个子节点**：删除该节点后，需要找到其右子树中最小的节点（或左子树中最大的节点），将这个节点的值替换到被删除节点的位置，然后删除该节点。这样可以保持二叉搜索树的特性。

题目询问在给定的二叉树中，哪一棵可能作为二分查找的决策树（排除外部节点）。这里的“决策树”特指**二分查找过程中隐含的比较路径结构**，需满足以下条件：
1. **符合二叉搜索树（BST）性质**：  
    每个节点的左子树所有键值小于该节点，右子树所有键值大于该节点。
2. **结构反映二分查找的分割逻辑**：  
    每次比较后，剩余搜索区间近似对半分，因此树应尽可能平衡，高度接近 O(log⁡n)。
