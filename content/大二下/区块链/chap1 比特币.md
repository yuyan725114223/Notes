【背景】数字技术发展，缺乏一个安全、高效、大家都能信任的协作机制
- 做可信任第三方，赋能实体经济，降低成本，易于监督
	- 希望货币非国家化
	- 希望通过计算机技术建立比国家信用更可靠的货币体系
【起源】中本聪提出”比特币“的电子现金系统。区块链是支撑比特币运行最底层的核心技术，比特币是区块链的第一个成功应用
- 第一个提出的区块叫做创世区块
【问题】
- 防篡改：将一段时间内的所有交易消息打包成一个区块，通过密码学技术（哈希）关联前后的区块；如果有人改了数据，前后的哈希码都改变了，以此实现快速校验和可追溯
	- 环签名/群签名/混币体制
- 去中心化：多老王记账，每个人手里有一个完整的账本，不一样的话需要共识机制，少数服从多数来保证所有账本的数据一样
	- 其实是多中心化
【智能合约】共识的规则
	区块链2.0时代
【区块链】可信的、分布式的账本，不可篡改、不可抵赖、可追溯历史
	融合创新：哈希算法，p2p网络，密码学，分布式存储，共识机制
	- 靠密码学达到可用不可见：默认对所有的节点数据可见但是需要保护商业机密
	- 哈希：Hash(N) = H( 第N个区块的所有交易数据 + 上一个区块的哈希值 Hash(N-1) + 随机数 )
【应用】供应链金融、产品溯源、政务数据共享、司法存证
【比特币】2100万个
	确认时间：PoW共识要10分钟出一个区块，且必须等6个区块确认（即1个小时），一笔转账才能最终到账。这就是为什么它很难当日常支付工具，太慢了！
三种形态
【联盟链/to B】只对特定的组织（比如一个联盟里面的企业）开放，能容忍33%的人作恶 去中介信任&中心化监管
【公有链/to C】任何人都可以参加，能允许51%的作恶节点
【私有链/to B-C】只在一个组织内部
->【侧链】为了代币发行/资产 在两链之间转移
->【互联链】把垂直领域的区块链相互连接起来，形成链网
【共识机制】统一的系统
【零知识证明ZKP】只需要验证转账是否合法，隐藏一些更加具体的信息 数据可用不可见 zcash应用
【同态加密】意思就是 不告诉真实的数据 但是得到了加密后的乱码，对乱码的操作结果等价于对原始数据的操作，把操作完之后的数据解码回去就好了
【挖矿PoW】不断修改区块头里面的一个随机数Nonce，使得整个区块头计算出的哈希值小于系统设定的当前目标值：**H( 区块头 + Nonce ) ≤ Target**
	因为是随机输出，所以其实是暴力枚举，所以叫工作量证明；系统根据全网算力调整target的值，控制找到区块的时间区间在10min左右
	target D(h)的意思是计算出来的target值前h位都是0
	**新难度 = 父块难度 + (父块难度 / 2048) × 调整因子**：维持15秒的出块时间
【一个纪元】重新生成一个DAG数据集的时间，每3w个区块，大约125小时；为了抵抗ASIC矿机，要保证挖矿的公平性
【PoS】权益证明，性能比较高
【PBFT拜占庭容错】【节点数量公式】联盟链里面**N ≥ 3F + 1**，N个节点F个叛徒
	希望好人数量>坏人数量其实是N>2F，不过因为还需要容忍消息延迟和重复投票，工程上严格需要 **N = 3F + 1**
	- 指定一个确定的轮值主节点提议记账，其他的所有附节点投票，只要有超过2/3的赞成票就记上账
	- 对于节点有限并且实名准入的联盟链来说比较合适
【RSA非对称加密】每个参与者有公钥和私钥，两个大质数通过欧拉函数生成（不知道，据说是这么干的，之后要学密码学再说）
- **加密**：**密文 = 明文 ^ e mod n** （e和n是公钥）
- **解密**：**明文 = 密文 ^ d mod n** （d是私钥）
数学上保证了，**用公钥加密的数据，只有配对的私钥能解开**；反过来，**用私钥签名的数据，只有配对的公钥能验证这个签名是你做的**（数字签名）。这就实现了课件里说的“不可抵赖”和“隐私安全”
【比特币通缩模型】每个区块奖励20个BTC，每21w个区块（大约4年）减半一次；等比数列加出来和还是2100万个区块
# 实验
用php把比特币区块链上的实时数据拽到网页上并存到mysql数据库
curl发起http请求之后，数据流向是：外部api-php接受json字符串-转换成php数组-渲染成html表格/写入mysql
```php
$loginUrl = 'https://api.blockcypher.com/v1/btc/main';
$ch = curl_init();  // ① 初始化一个cURL会话
curl_setopt($ch, CURLOPT_SSL_VERIFYPEER, false); // ② 跳过SSL证书验证
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);  // ③ 将返回结果作为字符串，而非直接输出
curl_setopt($ch, CURLOPT_URL, $loginUrl);        // ④ 设置要请求的API地址
$result = curl_exec($ch);  // ⑤ 执行请求，拿到返回结果
curl_close($ch);           // ⑥ 关闭会话，释放资源
```
要跳过SSL验证，因为刚创建的虚拟机的网页里面必然没有证书验证
去重：因为每次拉去当前最新区块都会拉到同一个区块，拿到的区块哈希和区块高度完全一样；检查区块hash是否一样，如果是一样的话就不拉了
