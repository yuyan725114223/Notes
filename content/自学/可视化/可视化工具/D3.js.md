# 条形图

```javascript
.domain(d3.groupSort(data, ([d]) => -d.frequency, (d) => d.letter))
```

把原始数据**分组并排序**，然后吐出一个排好序的“字母列表”。

- **按什么分组**：`(d) => d.letter` —— 把数据按照 `letter`（字母 A、B、C...）分组。
- **按什么排序**：`([d]) => -d.frequency` —— 计算每组里 `frequency`（频率）的值，加上负号 `-` 表示**降序**（频率最高的排最前面）。
- **最终结果**：`groupSort` 会返回一个数组，比如 `['E', 'T', 'A', 'O', ...]`（按频率从高到低排好的字母）。
  **所以这行 domain 的意思是**：横坐标轴按**频率从高到低**依次显示这些字母，而不是按 A-B-C-D 的默认字母表顺序。

```javascript
.domain([0, d3.max(data, (d) => d.frequency)])
```

最大值是遍历所有数据，找出 frequency 字段里的最大值（比如最高频率是 0.12）。

.attr(…)返回的是选择的图元本身
`transform` 可以一次性执行多个动作，按**从右到左**（或说从后往前）的顺序执行。例如：

```javascript
.attr('transform', 'translate(200, 100) scale(0.8) rotate(15)')
```

意思是：先把元素平移到 `(200,100)`，然后缩小到 80%，再旋转 15 度。但在 D3 中，最常用的几乎只有 `translate`，因为它用来处理**布局定位**。
