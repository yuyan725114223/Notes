# 框架&初始化

使用setuptools来把一个python文件变成一个二进制可执行文件？
entry\_points：记录
\_\_init\_\_.py：标识所在的文件夹是一个python包

- 版本里面第一个是breaking change，比如前后都不兼容or特别巨大的功能改变
- 第二个是一些功能增加，比如叫做feat
- 第三个就是一些比较小的更改，fix
  提交其实就是push到远程仓库
  config：一些控制，自动/手动加入的一些
  description：对仓库的一些描述
  hooks：比如说如果想在仓库更新的时候给钉钉发个消息
  @blabla：一个装饰器，装饰了之后会被typer（那个import的python插件）认出是一个操作
  一个python包的时候访问子目录可以用.
  python本来不会检查函数变量类型，但是xyx配了一堆参数就会了，所以还是都给参数和返回值加一点说明
  git的退出代码除了0都是异常？
  可以用.absolute()来寻找绝对路径
  如果有默认值/option的话就会被认为是一个选项，否则被认为是一个参数；直接标注一下就好
